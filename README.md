# 📊 Vibe 股票量化分析系统 v1.0

> 免费·开源·A股·手机端友好

## 🎯 核心能力

- **🔥 趋势策略**（主）：海龟交易法则改良版
- **🔄 行业轮动**（主）：申万一级行业动量排序
- **📊 多因子选股**（辅）：价值+质量+成长+动量+低波
- **⚖️ 智能风控**：单股≤20%、单行业≤30%、总仓位≤80%

## 🚀 部署到云端

1. Fork 本仓库
2. 访问 https://share.streamlit.io
3. 选这个仓库，Main file 填 app.py
4. 点 Deploy

## 💻 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
